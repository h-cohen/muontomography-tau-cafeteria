\section{Reproducibility}\label{sec:reproducibility}
The accompanying repository contains the three input ROOT histogram files, configuration, analysis package, tests, scripted figures and result JSON files. The data inventory records checksums and histogram conventions. The main configuration defines detector dimensions and fitting settings; a separate paper-input file records the on-site comparison values and numerical method inputs used in the manuscript. Numerical macros are generated from the result files, including a copy of those paper inputs. No fitted or measured value is typed into the manuscript body.

A clean full analysis is generated with \texttt{make all}. The individual ingest, self-calibration, opacity, reconstruction, analysis, validation, uncertainty, figures and viewer targets expose the same stages. The smoke mode, \texttt{make all FAST=1}, writes to a separate directory and is not a source of paper results. Package and dependency changes invalidate the stage targets. Stage metadata record the code revision and configuration hash; cached system matrices are keyed by their geometry and ray layout. An isolated run directory can be selected through the Make variable \texttt{RUNS} while retaining the full result and manuscript targets.

The full run reported here used the free-baseline configuration and the concrete-pinned estimator. All nominal, bootstrap and systematic beam-depth fits used the same measurement path, and the validation used that reported estimator rather than truth-supplied fit seeds. The repository identified for the accompanying code and data is \url{https://github.com/h-cohen/muontomography-tau-cafeteria}; the manuscript and corresponding source snapshot should be released together. The viewer is generated from the result and volume products. The arXiv archive target includes the manuscript, bibliography output and generated figures. Software tests and synthetic recoveries establish implementation consistency, while the independent on-site comparison and remaining model assumptions establish the limits of the physical inference.
